# BTC 심리차트

바이낸스 현물 BTC/USDT 캔들을 2022년부터 지금까지 보고, 표시를 남기는 개인용 차트.
지표 없이 캔들로만 읽는다. GitHub Pages에 그대로 올리는 정적 페이지 (빌드 없음).

- `index.html` — 화면·스타일
- `app.js` — 시세 받기, 실시간, 그리기 도구, 저장

## 쓰는 법

| 동작 | 방법 |
|---|---|
| 봉 간격 | 상단 5분 / 15분 / 1시간 (키 `1` `2` `3`) |
| 날짜 이동 | 날짜 버튼 → KST 날짜·시각 입력 (키 `G`). 그 봉이 가운데, 세로 점선 표시 |
| 최신으로 | 최신 버튼 (키 `L`) |
| 과거 보기 | 왼쪽으로 끌면 자동으로 더 받음 (1000봉씩) |
| 그리기 | 도구 버튼 → 차트 탭 1번 (수평선·점·레이) / 2번 (박스). 한 번 그리면 커서로 돌아감 |
| 지우기 | 지우기 버튼 → 지울 그림 탭 |
| 수정 | 도구 없이 그림을 탭 → 선택(주황 동그라미). 몸통을 끌면 이동, 동그라미를 끌면 그 꼭짓점만 이동. 빈 곳 탭 또는 `완료`로 끝, `삭제`로 지움 (PC는 `Delete`) |
| 취소 | 안내 바의 취소, 또는 `Esc` |
| 단축키 | `H` 수평선 · `B` 박스 · `D` 점 · `R` 레이 · `E` 지우기 |
| 와이드 (폰) | 상단 ▭ 버튼 → 화면이 90° 돌아감, 폰을 왼쪽으로 눕혀서 보기. 다시 누르면 원래대로. 켜 둔 상태는 기억함 (폰을 실제로 가로로 돌리면 자동으로 꺼짐) |

**전체 화면으로 보기 (iPhone)**: 사파리에서 공유 버튼 → `홈 화면에 추가` → 홈 화면의 '심리차트' 아이콘으로 열면
주소창·탭 막대 없이 화면 전체를 쓴다. (사파리 안에서는 웹페이지가 전체 화면을 켤 수 없다.)
홈 화면 앱은 사파리와 저장 공간이 따로라서, 사파리에서 그린 그림은 내보내기 → 가져오기로 옮긴다.

그림은 기기 브라우저(localStorage)에 자동 저장된다. 폰 ↔ PC 이동은 저장 버튼에서
파일(.json) 또는 텍스트로 내보내고 다른 기기에서 가져오기 (합치기, 중복 없음).

## 시세 출처

- REST: `data-api.binance.vision` → `api.binance.com` → `api1.binance.com` → corsproxy.io 순서로 시도
- 실시간: `wss://data-stream.binance.vision` (안 되면 `stream.binance.com:9443`), 끊기면 자동 재연결 후 빠진 봉 채움
- 키·로그인 불필요 (공개 시세만)
